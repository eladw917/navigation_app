# Notebooks

1. Start the API (`npm run dev` from repo root).
2. Install deps once:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r notebooks/requirements.txt
```

3. Open `01_api_usage.ipynb` and run all cells.

`API_BASE_URL` defaults to `http://127.0.0.1:3010`. The notebook never reads the HeiGIT key.
